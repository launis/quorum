# IMPLEMENTATION PLAN: Topological Causal Synthesis Projection, SDUI Quiescent Summary Refinement & Scientific Formalization

## 1. Objective & Architectural Background

Forensic audit of the full-scale production execution `exe_01a1a1d04e3073d58976d27546eca466` (report `rep_01a1a1dcbffe71809a6dbaccffb20938`) against the theoretical guarantees in `@[docs/tiede.md]` revealed that while Phase 1 neurosymbolic DAG execution and the 0-token Pure Stateless Causal Cohesion Evaluator (`CausalCohesionEvaluator`) functioned with mathematical precision ($108/108$ criteria passed, $0\%$ chimeric quotes, $\kappa = 0.9230\text{–}0.9425$ across replication runs, $44$ causal nodes, $48$ verified dependency edges, $16$ isolated deliverable claims, and $\text{CohesionScore} = 0.3333 \implies 20.0\%$ BARS score), the mined causal topology did not surface visibly in Phase 2 narrative syntheses (`Executive Summary`, `2D Matrix Sections`, `XAI Highlights`, and `Row Explanations`).

Root cause analysis identified three specific architectural gaps across Phase 2 synthesis and Pillar 4 SDUI presentation, plus one documentation synchronization target in `@[docs/tiede.md]`:

1. **Root Cause 1 — PostgreSQL JSONB Trace Hydration Asymmetry in `@[backend_v2/workers/synthesis_worker.py#L95-L661]`:**
   During Phase 1 DAG execution, `wave_orchestrator_stage.py` emits the composite fusion payload as `TraceEvent(step_name=step_id, event_type="output", content={"fusion": fusion_res})`, and `causal_discovery_engine.py` emits `content={"graph": graph_res}`. When `ExecutionRecord` is persisted to PostgreSQL 19 JSONB and reloaded by `generate_profile_synthesis_and_pdf_task` (`await repo.get_execution(execution_id)`), `StateProjector` unpacks these events into `final_inputs: list[StepOutputDTO]` with `dto.block_id == "fusion"` and `dto.block_id == "graph"`. While `BlueprintTransformer.build_report_dto` (`@[backend_v2/services/blueprint.py#L72-L732]`) hydrates `causal_result` from `reversed(results)` via `TypeAdapter(CausalTdaFusionResultDTO | CausalGraphPayloadDTO).validate_python(dto.payload, strict=False)`, `synthesis_worker.py` previously only matched direct in-memory `isinstance(evt.content, (CausalTdaFusionResultDTO, CausalGraphPayloadDTO))` on `execution.execution_trace`. Consequently, after a PostgreSQL JSONB roundtrip or when `falsified_claims` is empty, `causal_payload` in `synthesis_worker.py` evaluated to `None`, starving all four Phase 2 synthesis tasks of `<causal_diagnosis>`.
2. **Root Cause 2 — Quiescent ATMS Baseline Projection Omission in `@[backend_v2/models/dtos/synthesis.py#L133-L473]` and `@[backend_v2/models/prompts/synthesis/synthesis_directives.py]`:**
   When Algorithm 1 (ATMS Truth Maintenance) operates in its quiescent baseline state ($RC = \emptyset$, $108/108$ criteria passed, `root_cause_diagnoses = []`, `falsified_claims = []`, `prescriptive_remediations = []`), `CausalSynthesisBriefDTO.format_for_prompt()` only emitted two scalar lines (`Intact Propositions: 44/44` and `Logical Cohesion: 0.33`). It omitted the concrete **Isolated Unlinked Claims ($\mathcal{V}_{\text{iso}}^{\text{deliv}}$)** (the 16 degree-zero deliverable propositions that caused the $0.33$ cohesion score) and the **Established Causal Chains ($\mathcal{E}_{\text{deliv}}$)** (`source_claim -> target_claim: reasoning`), as well as `largest_component_ratio` ($r_{\text{LCC}}$) and `branch_convergence_ratio` ($r_{\text{conv}}$). Similarly, `CAUSAL_TDA_DIAGNOSIS_MANDATE` instructed the synthesis LLM on negative root-cause fault chains and Toulmin rebuttals, but did not mandate grounding narratives and row explanations in topological cohesion metrics, isolated degree-zero islands, and verified premise-to-conclusion chains during quiescent baseline runs.
3. **Root Cause 3 — Quiescent Summary Card Ambiguity in `@[backend_v2/services/sdui/adapters/causal_graph_adapter.py#L34-L353]`:**
   In `CausalGraphAdapter._build_summary_text` (`#L310-L353`), `SduiCausalGraphBlock.summary` unconditionally rendered `"{intact_claims_count}/{total_claims_count} väitettä ehjänä. {diagnoses_count} juurisyyn ketjua tunnistettu."`. When `diagnoses_count == 0` and `anti_fluff_audit` is present (`logical_cohesion_score = 0.33`, `isolated_concept_count = 16`, `len(critical_edges) = 48`), displaying `"44/44 väitettä ehjänä. 0 juurisyyn ketjua tunnistettu."` without surfacing the `48` causal links, `16` isolated claims, and `33%` topological cohesion score created an apparent contradiction against the `20.0%` Causal Cohesion matrix score in both the Flutter SDUI dashboard and the compiled PDF report.
4. **Scientific Paper Synchronization in `@[docs/tiede.md]`:**
   Formalizing the **Topological Synthesis Projection** ($\Phi_{\text{synth}}$ receiving both negative ATMS fault attributions $RC, \mathcal{F}_{\text{Toulmin}}$ and positive/structural deliverable topology $\mathcal{V}_{\text{iso}}^{\text{deliv}}, \mathcal{E}_{\text{deliv}}, r_{\text{LCC}}, r_{\text{conv}}$ when $RC = \emptyset$) in Section 4.2.1 and Section 7.2 (Barrier 4) of `@[docs/tiede.md]`, while documenting the confirmatory third production replication run (`exe_01a1a1d04e3073d58976d27546eca466`, $\kappa = 0.9230\text{–}0.9425$, $P_o = 96.36\%\text{–}97.27\%$) in Section 8.1.
