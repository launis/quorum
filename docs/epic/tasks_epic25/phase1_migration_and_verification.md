# Epic 25, Phase 1: Python Migration & Frontend Verification

## Objective
Execute the deterministic `scripts/epic25_prune_extensions.py` to prune `output_extensions` from all non-evaluative (`category_id != "matrix"`) PromptBlocks in the `seed_data.json`. Following the pruning, re-seed the TinyDB local database and perform manual UI verification in the Flutter Desktop Admin Studio to ensure "Citation", "Coaching", and "Justification" toggles are properly hidden.

## Context & Targets
- **TARGET (Modify)**: `c:\src\quorum\backend_v2\seed\seed_data.json` (Modified by the script)
- **TARGET (Modify)**: `c:\src\quorum\data\db_v2.json` (Modified by `run_seed.py`)
- **CONTEXT (Read-Only)**: `c:\src\quorum\scripts\epic25_prune_extensions.py`
- **CONTEXT (Read-Only)**: `c:\src\quorum\client_app_v2\lib\features\studio\models\prompt_block.dart`

## Execution Steps
1. **Run Pruning Script**:
   Execute the pre-existing utility script `epic25_prune_extensions.py` via PowerShell.
   Command: `uv run python scripts/epic25_prune_extensions.py`
2. **AI Spot Check & Validation**:
   Review the stdout AI Spot Check generated by the script. Respond with `y` to confirm the backup creation, mathematical balance, and Pydantic integrity are intact. 
3. **Database Seeding**:
   Propagate the pruned seed file to the local database.
   Command: `uv run python backend_v2/seed/run_seed.py local`
4. **Testing Frontend Render**:
   - Start the frontend client (if not running).
   - Navigate to the PromptBlock configurations in Admin Studio V2.
   - Verify that for Synthesis or Instruction blocks, the UI automatically hides specific toggles (because the `output_extensions` list is now empty).

## Verification & Quality Gate Plan
- **Verification Command 1**: `uv run pytest backend_v2/tests/unit/test_seed_schema_alignment.py -v` (Verify that the new `seed_data.json` strongly aligns with Opaque ID patterns and Pydantic validation).
- **Verification Command 2**: Check `c:\src\quorum\backend_debug.log` to assert no hidden schema mismatch warnings during `run_seed.py`.
- **Flutter Build**: Run `uv run python scripts/flutter_audit_loop.py client_app_v2` to assert no regression in Freezed UI schema bindings or Dart compilation.
