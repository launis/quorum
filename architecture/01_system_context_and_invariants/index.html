    System Context & Core Invariants

    1. Executive Summary

    The System Context & Core Invariants capability forms the foundational constitution of the Compound AI System. It establishes the absolute architectural invariants that govern how all other components (Backend, Frontend, LLM Engine) must behave. This capability exists to ensure Forensic Sovereignty, deterministic execution, and the total eradication of silent failures, LLM hallucinations, and undocumented state mutations.

    2. Architectural Principles & Invariants

    Quorum operates on strict structural boundaries, deterministic execution, and end-to-end auditability:

    2.1. Universal Fail-Fast, Zero-Default Contracts & Strict Schema Validation

    All data crossing system boundaries is strictly validated against immutable schemas (Pydantic V2 in Python, Freezed in Dart). Fallback chains, silent error absorption, and duct-tape workarounds are eliminated. Critical domain, identity, naming, relational, and creation DTO fields (id, *_id, *_ids, slug, name, label, title, storage_mode, updated_by, created_by, and target_identifier) never declare hardcoded scalar, string, or enumeration default values (Field(default=...) or non-None assignments in Python models, or SQL DEFAULT clauses in PostgreSQL 19 DDL), and service or API layers never mutate missing inputs into fallback defaults (if value is None: value = default), branch on test-environment variables (PYTEST_CURRENT_TEST), or maintain in-memory shadow fallback dictionaries (self._local_*, self._deleted_*, self._memory_*). If data is missing, malformed, or an expected state is not reached, the system halts immediately with an explicit AppException on the backend or renders an AppErrorBoundary on the client. Masking errors by returning empty arrays or hiding UI widgets is strictly prohibited.

    2.2. Zero Permissive Typing, Primitive Obsession Eradication & Dot-Notation Transit

    All domain, service, orchestrator, and hook layers enforce 100% typed transit using immutable Pydantic V2 DTOs configured with ConfigDict(strict=True, extra="forbid", frozen=True). Naked dictionaries (dict[str, Any], list[dict], TypedDict), permissive type coercions (cast(Any, ...)), structural duck-typing (isinstance(data, dict)), dictionary pattern matching, type laundering via TypeAdapter with dictionary types (strictly banned under fatal rule QGR018), and permissive model configurations (extra="allow", extra="ignore") are eliminated. Type-checker and linter suppressions are completely eradicated across production, test, and script codebases: inline # noqa comments, type-ignore annotations (# type: ignore), and unchecked casts are strictly prohibited, backed by global type-checking configurations enforcing unused ignore warnings and standard-library configuration suppression ratchets.

    Direct Pydantic DTO state transit is enforced across all pipeline stages: intermediate dictionary wrappers, local wrapper DTOs, and untyped runtime dictionary accumulators (updated_dynamic = dict(...), d[k] = v) are prohibited. State reduction routes pipeline deltas, cognitive modifications, and evaluative matrix scores directly into strongly typed fields on GlobalContextVarsDTO (specifically evaluative_matrices: dict[str, float] | None = None) and ExecutionMetadata via pure functional updates (.model_copy(update={...})), preserving direct, unboxed DTO transit with zero intermediate dictionary wrapping.

    Primitive Obsession across nested collections is completely eradicated: nested dictionaries (dict[..., dict]), primitive dictionary lists (list[dict]), untyped configuration dictionaries, and mutable worker telemetry bags are prohibited. Structured breakdowns, message payloads, aesthetic configurations, worker telemetry, and parser returns are encapsulated in dedicated, immutable Pydantic V2 DTOs (specifically LevelStatsDTO for level metrics, LLMMessageDTO for hydrated messages, frozen aesthetic DTOs in sdui_rules for visual hydrators, StepTelemetryEntryDTO for telemetry, and ParsedMatricesResultDTO for core parser outputs). Pipeline state transit and trace events enforce closed payload unions and typed metadata DTOs (TraceEventMetadataDTO, ProgressTracePayloadDTO), eliminating intermediate double-serialization across execution boundaries. Dynamic dictionary indexing, two-argument fallback lookups (dict.get("key", default)), lazy default fallback operators (a or "default"), and runtime reflection (getattr(), hasattr(), setattr()) are prohibited. Raw dictionary conversions and Open-JSON structures are confined strictly to an authoritative, frozen set of physical boundary files (quarantining low-level storage drivers, logging sanitizers, telemetry collectors, and foundational provider adapters) and authorized external specifications (OpenAPI, MCP protocols, and problem details representations).
