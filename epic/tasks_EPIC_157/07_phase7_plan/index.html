    3. Obsolete Mock-Emulation Subsystem:
    4.     6. backend_v2/tests/unit/fakes/test_in_memory_repositories.py imports DynamicRepoMethod and InMemoryBlueprintTransformerRepository (lines 40, 43) and defines test_in_memory_blueprint_transformer_repository_and_dynamic_method (lines 765-838). This test function and its imports must be deleted.
    7. Decorator Repository Patches & Return Value Assignments in Worker Synthesis Tests:
    8. backend_v2/tests/unit/test_worker_synthesis.py (16 test functions at lines 67, 268, 322, 374, 399, 445, 479, 565, 685, 760, 845, 936, 1012, 1122, 1168, 1210) and backend_v2/tests/unit/test_worker_synthesis_accumulation.py (1 test function at line 119) declare @patch("backend_v2.workers.synthesis_worker.UnifiedWorkflowRepository") on function decorators and subsequently assign mock_repo_class.return_value = mock_repo. These 17 test sites must be migrated to with patch("backend_v2.workers.synthesis_worker.UnifiedWorkflowRepository", return_value=mock_repo): wrapping worker task execution.
    9. Under-Enforced QGR014 AST Guardrail:
    10. scripts/_ast_guardrails.py only inspects spec=I*Repository keyword arguments and @patch calls when "service" is present in the file path, permitting ad-hoc attribute assignments (repo.get_user = AsyncMock()), return value overrides (repo.get_user.return_value = ...), keyword mock injection (HookDependencies(exec_repo=AsyncMock())), and string-target patches outside services.
