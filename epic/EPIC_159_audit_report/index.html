    1. Executive Summary & Architectural Modernization

    @[docs/epic/EPIC_159_DYNAMIC_MCP_ARCHITECTURE.md] establishes Quorum's complete transition from static, bespoke Python tool wrappers (tavily.py, wikipedia.py, tavily_search_client.py, wikipedia_client.py) and loose dict[str, JsonValue] parameter schemas to a 100% dynamic, protocol-agnostic Model Context Protocol (MCP 2025-03-26) architecture.

    1.1 Solved Architectural Bottlenecks

    1. Eradication of Bespoke Tool Wrapper Proliferation:
    2. Previously, connecting a new external tool required authoring bespoke Python clients, static DTOs, and hardcoding dispatch branches.
    3. The system now features a protocol-agnostic, asynchronous GenericMCPClient (@[backend_v2/services/mcp/generic_mcp_client.py]) supporting both Streamable HTTP and HTTP+SSE transports with dual wire framing (application/json and text/event-stream SSE frame parsing).
    4. Zero Permissive Typing & Schema AST Validation:
    5. Replaced permissive dict[str, JsonValue] in AllowedMCPTool and MCPFunctionDefinitionDTO with recursive self-referential Pydantic V2 DTOs (MCPToolSchemaPropertyDTO, MCPToolInputSchemaDTO in @[backend_v2/models/dtos/mcp.py]).
    6. Removed system_config.py and mcp.py from OPEN_JSON_EXEMPTION_FILES in AST guardrails.
    7. Runtime Schema Compilation (pydantic.create_model):
    8. SchemaFactory.create_mcp_tool_argument_model compiles stored MCPToolDescriptorDTO manifests into runtime Pydantic V2 models at execution time, enabling native LLM function declaration synthesis with zero hardcoded classes.
    9. Deterministic Namespace Routing:
    10. AliasRegistry binds tools to collision-free {gateway_slug}__{tool_id} namespaces with bijective split("__", 1) parsing into ParsedMCPToolAliasDTO.
    11. ToolDispatcher dynamically resolves gateway configs, verifies step-level tool allowlists (step.allowed_mcp_tools), and returns MCPAuditTrace with OpenTelemetry mcp.tool_call span attributes.
    12. SSRF & Indirect Prompt Injection Firewall:
    13. MCPUrlValidator blocks loopback, private subnets, cloud metadata (169.254.169.254), and redirects via non-blocking asyncio.to_thread.
    14. External tool responses are truncated at sentence boundaries (enforce_sentence_boundary_budget) and encapsulated in <![CDATA[...]]> with XML Sandwich structural framing (TemplateProcessor.encapsulate_payload).
    15. Desktop-Class Quorum Studio Integration:
    16. Modernized McpGatewayView with maxWidth: 1200 canvas containment, live "Connect and Discover Tools" action, read-only inspected parameter schema preview table, typed ToolCapability dropdown, and per-tool allowlist switches.
    17. Updated StepBuilderView with per-gateway {gateway.slug}__{tool.toolId} FilterChip selectors.
